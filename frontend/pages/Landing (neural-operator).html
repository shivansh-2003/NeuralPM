How it works
Four agents. One shared memory.
Every action is stored, compressed, and made available across all agents — so a risk caught by one shapes an assignment made by another.
📥01
You act or decide
A task is created, a risk is dismissed, an assignment is overridden. Every action is a signal.
🧠02
Memory Agent processes it
The event is ingested, relevance-scored, and tiered: active, compressed, or archived with a decay clock.
✦03
All agents respond smarter
Risk, Assignment, and Cascade agents pull from that memory — their next output is shaped by what you just did.
